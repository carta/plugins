# Document types on the Documents page

The exact names the firm Documents page's type filter offers. The list's
`document_types` filter matches a name exactly, so send a name from this list
verbatim, including its capitals and punctuation.

## What users call them

| The user says | Send |
|---|---|
| W-9, W-8, W-8BEN, W-8BEN-E, W-8IMY | `W8/W9` (one type holds W-8s and W-9s) |
| tax form, tax documents | `W8/W9`, `Tax - Schedule K-1`, `Tax`, `Tax - Estimate` and `Tax Return` |
| K-1, Schedule K-1 | `Tax - Schedule K-1` |
| capital call, capital call notice | `Capital Call Notice` and `Capital Call` |
| distribution notice | `Distribution Notice` |
| NDA, confidentiality agreement | `Non-Disclosure Agreement (NDA)` |
| LPA, limited partnership agreement | `Limited Partner Agreement (LPA)` |
| SPA, stock purchase agreement | `Stock Purchase Agreement (SPA)` |
| IRA, investors' rights agreement | `Investors Rights Agreement (IRA)` |
| ROFR, co-sale agreement | `Right of First Refusal & Co-Sale Agreement (ROFR)` |
| voting agreement | `Voting Agreement (VA)` |
| sub docs, subscription documents | `Subscription Document (contains Investor Questionnaire, Subscription Agreement, etc.)` and `Subscription Agreement` |
| PPM | `Private Placement Memorandum` |
| IAA, advisory agreement | `Investment Advisory Agreement (IAA)` |
| capital account statement, CAS | `Capital Account Statement` |
| COI, charter | `Amended and Restated Certificate of Incorporation (COI)` |
